# Vidrieras Web

**Páginas web modernas, profesionales y a medida para tu negocio.**

Vidrieras Web es un proyecto enfocado en crear sitios web atractivos, claros y adaptables a celulares, tablets y computadoras. La idea es ayudar a emprendimientos y negocios establecidos a mostrar mejor sus productos o servicios y facilitar el contacto con sus clientes.

## ✨ Qué vas a encontrar

- **Diseño moderno y profesional:** una presencia digital cuidada y coherente con cada marca.
- **Diseño adaptable:** experiencia pensada para distintos tamaños de pantalla.
- **Navegación clara:** información organizada para que las personas encuentren lo que buscan.
- **Contacto directo:** opciones para que los potenciales clientes puedan realizar consultas fácilmente.
- **Propuestas personalizadas:** cada sitio puede adaptarse al rubro, los objetivos y la identidad del negocio.

## 🖥️ Sitio y demostraciones

El portfolio reúne ejemplos visuales de distintos tipos de páginas web:

- **Distribuidora:** catálogo y presentación de productos.
- **Gimnasio:** propuesta web para un espacio de entrenamiento.
- **Aura Studio:** concepto de sitio para un estudio de estética o bienestar.
- **Punto Obra:** concepto de sitio para el rubro de construcción y materiales.

> **Importante:** las páginas de demostración son ejemplos visuales para mostrar ideas de diseño y posibles funcionalidades. Sus textos, imágenes, productos y datos pueden ser ilustrativos; no necesariamente representan negocios reales ni ofertas vigentes.

## 🚀 Publicación

Este proyecto está preparado como un sitio estático. Para publicarlo con GitHub Pages:

1. Subí el archivo principal como `index.html` en la raíz del repositorio.
2. Entrá en **Settings → Pages**.
3. En **Build and deployment**, elegí **Deploy from a branch**.
4. Seleccioná la rama `main` y la carpeta `/(root)`.
5. Guardá los cambios y esperá a que GitHub publique el sitio.
